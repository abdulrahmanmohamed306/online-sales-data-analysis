# 📊 Global Online Sales & Revenue Intelligence Analysis

An end-to-end data analytics project leveraging real-world online transaction datasets. Focused on cleaning transaction logs, evaluating regional sales distribution, and identifying high-revenue product categories using Python and modern data analytics tools.

---

## 🚀 Project Overview
This project simulates real business intelligence workflows to extract actionable financial and sales insights. By bridging accounting expertise with data analytics, the project analyzes transaction logs to optimize product pricing, evaluate regional performance, and drive strategic decision-making.

---

## 🛠️ Tech Stack & Tools
- **Programming Language:** Python (Pandas, NumPy)
- **Data Visualization:** Seaborn, Matplotlib
- **Database & Querying:** SQL Server
- **Dashboarding / Presentation:** Power BI / Next.js Portfolio Integration

---

## 📈 Key Analytical Findings
- **Top Revenue Category:** **Electronics** generated the highest total revenue (**$34,982**), outperforming all other product categories significantly.
- **Leading Region:** **North America** led regional sales performance with **$36,844** in total revenue, followed by Asia and Europe.
- **Average Order Value (AOV):** Evaluated across online transactions to measure customer spending behavior.
